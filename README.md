# AnimatedWidgets

AnimatedWidgets 是一套基于 Qt Widgets 的 C++ 动画控件库，支持 Qt 5 和 Qt 6，使用 C++17 和 CMake 构建。

**项目仍在开发中，控件接口和默认样式可能随迭代调整。**

- **控件库**包含按钮、复选框、单选框、开关、输入框、下拉框、弹出菜单、滑块、进度条和日历等控件。部分控件支持配置状态颜色、动画时长和缓动曲线。
- **Gallery** 提供按控件分类的交互示例。
- **Qt Designer 插件**支持在 `.ui` 文件中使用自定义控件。**Style Editor** 支持调整样式、实时预览并生成 C++ 设置代码。
